# 🌐 Plataforma Corporativa - Ecosistema de Automatización e IA

> **Sitio web unificado para presentar servicios de automatización inteligente, desarrollo de apps con IA, redes ofensivas y consultoría estratégica.**

---

## 📋 Descripción del Proyecto

Este repositorio contiene el código fuente de la página web corporativa diseñada para envolver y presentar un ecosistema integrado de 4 servicios tecnológicos especializados:

| # | Servicio | Enfoque Principal |
|---|----------|-------------------|
| 1 | **Automatización Inteligente** | Flujos de trabajo autónomos con n8n + Claude |
| 2 | **Desarrollo Web/Apps con IA** | Aplicaciones inteligentes (React/Flutter + Claude API) |
| 3 | **Redes Ofensivas** | Servicios DNS, TCP y ejecución de módulos Metasploit |
| 4 | **Consultoría y Estrategia** | Auditoría, implementación y entrenamiento |

**Objetivo:** Proveer una interfaz profesional, clara y unificada que comunique el valor de cada servicio, inspirando confianza y mostrando la integración tecnológica (Claude, n8n, Metasploit) como ventaja competitiva.

---

## 🏗️ Estructura del Sitio Web

La web sigue el modelo de sitios corporativos tecnológicos (como IBM), con páginas independientes pero cohesionadas bajo una misma marca.
